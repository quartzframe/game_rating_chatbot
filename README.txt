GameRate AI - Game Rating Chatbot

Project:
AI-powered game rating and review chatbot using Flask and Gemini API.

Files:
- app.py
- templates/index.html
- chatbot_config.txt
- requirements.txt
- .env
- .gitignore

Important:
Put your Gemini API key in .env:
GEMINI_API_KEY=your_key_here

The chatbot focuses on game-related questions and gives explainable
AI assessments rather than pretending to provide official scores.

Run:
1. Create a virtual environment.
2. Install requirements.txt.
3. Add your Gemini API key to .env.
4. Run: python app.py
5. Open the local Flask URL shown in the terminal.
